📷 สแกน QR Code

ระบบสมาชิกและเช็กอินกิจกรรม
กด “เปิดกล้อง” เพื่อเริ่มสแกน QR Code
วิธีใช้งาน
1. กด “เปิดกล้องหลัง”
2. อนุญาตให้เว็บไซต์ใช้ Camera
3. หันกล้องไปที่ QR Code
4. เมื่ออ่านสำเร็จ ระบบจะกลับไปยัง Web App โดยอัตโนมัติ

หากกล้องเปิดไม่ได้ สามารถเลือกภาพ QR จากคลังรูปในโทรศัพท์ได้
